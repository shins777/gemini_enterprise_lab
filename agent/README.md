# Agent Modules

This directory contains the custom enterprise AI agent implementations for the Gemini Enterprise Lab workspace.

## 📁 Agents Directory

- **[`agent_search/`](./agent_search)**: A2A (Agent-to-Agent) compatible Search Assistant powered by Google ADK and Gemini 2.5 Flash. It has been fully deployed to Vertex AI Agent Engine and is integrated with the Google Search tool for comprehensive, real-time web querying and synthesis.

For details on configuration, local hosting, deployment, and testing clients, please see the specific agent subdirectories.
